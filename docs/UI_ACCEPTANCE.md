## 共用状态

- 会话：真实登录成功导航、401确认框错误、重新导航回登录页已验证。临时VIEWER提交容器重启得到403且任务数为0；不是所有资源写操作的逐项授权验收。
- Key授权：隔离浏览器仅对本地源附加专用Bearer，验证共用运维入口缺scope/高危许可拒绝、范围外节点禁用，另发真实请求确认服务端403；四个专用Key创建任务数为0。吊销后浏览器请求401，原文临时文件已移除；这不是新增Key网页登录功能。
- 查询：真实空态与非空态已见于上述页面。本地浏览器阻断RPC时显示连接错误和重试入口；恢复连接后定时刷新恢复列表。手工重试按钮及慢请求加载态仍需明确验证。
- 任务：多数运维页已通过实际操作进入任务详情，确认来源、日志、结果与失败状态。成功/失败且无日志的任务已分别通过页面验证，不再显示等待或混合未知结果；其他状态的无日志说明已实现但尚未逐态浏览器验收。非幂等结果不明时不得换键盲目重提；现有响应丢失测试是API级证据。
- 计划记录：按持久scheduleId筛选并保留节点授权；真实页面65条均为指定节点/CRON来源，日志入口打开成功系统信息结果。搜索无匹配空态及原生选择+删除后恢复100条均验证；前次自动化组合键未选中文本，不计作页面缺陷。
- 可访问性：共用表格已验证键盘横向滚动和焦点轮廓，Docker页历史axe检查为0违规/1人工确认项；不能据此宣称所有页面可访问性通过。

## 执行约束

使用本轮专用资源，不操作未知节点、已有通知或生产服务。测试身份与一次性密钥按ID清理；密钥原文、Cookie、Agent状态及截图中的敏感信息不入库。失败/超时须查看实际页面、任务或资源状态后判断，未执行和间接证据均不计通过。

生产ACME、长期多节点、公网稳定性及异地灾备不属于本地页面验收，条件和剩余事项见[开发计划](PLAN.md#部署验收)。
