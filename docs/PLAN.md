## 架构与约束

- Web、MCP、Cron 共用 `src/lib/services` 中的输入契约、授权和任务机制。Agent 负责采集与执行，Manage 负责展示、管理和调度。
- PostgreSQL 是任务状态的事实来源，Redis 只做临时协调/限流。非幂等任务最多尝试一次，结果不明保留 `UNKNOWN`，通过 Agent journal 对账。
- 业务请求、调度和分发均检查当前身份权限。删除或吊销 Key 不得使旧任务、计划或探针获得用户的完整权限。
- 生产外部通信使用 HTTPS/TLS；本地开发可显式允许受限例外。私钥、凭据、备份与运行状态不入库。
- 原始指标按月分区，默认保留 30 天；CPU/内存小时聚合保留 365 天。持久水位、48 小时回看、停机补偿和清理在同一维护事务中完成，见 [数据库文档](database.md)。
